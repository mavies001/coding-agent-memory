# Judge rubric (same for every stage and every judge)

Rank branches in this order. Earlier items outweigh later ones.
1. Tests pass and the task is actually done
2. Correctness and no regressions
3. Small, focused diff (no unrelated edits, no stray files)
4. Simplicity and readability
5. Style consistency with the repo

Judge output format: ranking, one-line reason per branch, the pick, and what the
losers should learn. The human makes the final call and records any override.
